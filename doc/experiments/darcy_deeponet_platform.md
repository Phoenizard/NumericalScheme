## 论文依据与共同设置

依据 [PB-SAV Momentum](../paper/PB_SAV_Momentum.pdf)
（[arXiv:2609.13569v1](https://arxiv.org/html/2609.13569v1)，§4.3，式 (70)–(73)，Figure 5、Table 3）。
论文的 PDE 为

$$
-\nabla\!\cdot(a\nabla u)=1\quad\text{in }(0,1)^2,
\qquad u|_{\partial\Omega}=0.
$$

这是监督式稳态算子学习 $a\mapsto u$；没有物理时间步，也不使用 PINN 的 PDE 残差损失。

| 项目 | 新平台固定设置 |
| --- | --- |
| 渗透率 | 沿用两相 3 / 12；平滑高斯白噪声后以 0 为阈值 |
| 随机场细节 | 标称相关长度 0.12；σ=0.12/(√2h)，`reflect`，`truncate=4` |
| 网格与参考解 | 33×33，h=1/32；调和面平均、守恒五点差分、稀疏直接求解；相对线性残差 ≤10⁻¹⁰ |
| 数据划分 | 新生成固定的 128 训练 / 32 验证 / 64 测试场；数据种子 20261106 |
| 随机流 | `SeedSequence(20261106).spawn(3)` + PCG64，顺序为 train / validation / test |
| 数据版本 | 拟保存为 `data/darcy_deeponet_v2.pt`；旧文件不覆盖，不筛选有利样本 |
| 输入 | 渗透率保留 3 / 12，坐标保留 [0,1]² |
| 网络 | 沿用当前卷积分支、3 层 64 宽 tanh trunk、64 维内积及边界因子 16x(1−x)y(1−y) |
| 初始化 | 沿用当前 PyTorch 默认初始化；各方法读取同一份初始权重快照 |
| 种子 | 校准初始化用 0；正式配对初始化用 42、101、211、307、401 |
| 预算与环境 | 每组 5,000 次全批量更新，CPU、float64、4 线程 |

卷积核、步幅、平滑规则和初始化以仓库配置为准，不把论文未披露的细节视为已经复现。
五个正式种子共享同一数据集，只改变初始化；统计描述初始化稳健性，不代表五个独立数据集。

### 输出尺度与目标

只用训练集计算一个标量，不减均值：

$$
s^2=\frac1{N_{\rm tr}N_x}\sum_{j,\ell}u_j(x_\ell)^2,
\qquad N_x=33^2,
\qquad \widehat u_\theta(a;x)=s\,v_\theta(a;x).
$$

$v_\theta$ 为现有网络输出。$s>0$ 随数据冻结，验证与测试只使用这个 $s$，边界仍严格为零。

$$
\boxed{
E_1(\theta)=\frac1{2N_{\rm tr}N_x}\sum_{j,\ell}
\left(v_\theta(a_j;x_\ell)-\frac{u_j(x_\ell)}s\right)^2,
\quad E_2(\theta)=\frac\lambda2\|\theta\|^2,
\quad E=E_1+E_2,
\quad \lambda=3\times10^{-5}.
}
$$

PB 固定沿用数据项与 L2 项这两组（M=2），所有参数和偏置参与 L2。
原始物理量的 half MSE 同时记录为 $s^2E_1$；零预测的归一化 $E_1$ 恰为 1/2。

这是项目 v2 的明确训练定义，不是事后缩放旧曲线，也不声称是论文未披露的归一化方式。
固定 λ 的意义随输出参数化改变，旧实验不能与 v2 混表比较。

## 比较方法与学习率

主实验只选一种 PB 配置：动量、AMSGrad 型缩放与完全 Relax 均开启。
两种 PB 方法共同使用 β=0.9、α=0.5、β₂=0.999、ε=10⁻⁸、ρ=1；
SAV 的 C=0，SESAV 的 k=16，E⁰、Eᵢ⁰ 初始化后冻结。
这里同 α 表示采用各自已定义的算法，不表示两种 PB 矩阵相同。

| 方法 | 梯度所对应的目标 | 学习率安排 | 比较用途 |
| --- | --- | --- | --- |
| PB-SAV 动量 | E₁+E₂ | 校准后固定 η* | 主要参照 |
| PB-SESAV 动量 | E₁+E₂ | 与 PB-SAV 相同 η* | 同级算法比较 |
| SGD + momentum=0.9 | E₁+E₂ | 单独校准并固定 | 同目标常规基线；实际为 full-batch heavy-ball |
| Adam，β=(0.9,0.999)、ε=10⁻⁸ | E₁+E₂ | 单独校准并固定 | 同目标自适应基线 |
| AdamW，β=(0.9,0.999)、ε=10⁻⁸ | E₁；解耦 weight decay=3×10⁻⁵ | 单独校准并固定 | 预测效果的实用参照 |

AdamW 不再叠加 E₂ 的梯度；其更新不等价于最小化其他方法的 E，不能用它证明同目标优化优势。
同样的 λ 数值不表示耦合正则与解耦衰减强度等价。
PB-ESAV 保留为后续可选对照；本轮不展开其他分组、k 扫描或多套 PB 配置。

### 为什么不直接搬用非线性回归控制器

当前控制器显式形成 $J^\top J$ 并求特征值。
按现有 Darcy 大小，float64 的完整输出 Jacobian 约 53.51 GiB，单个参数 Gram 矩阵约 19.78 GiB；
这还没有计入自动微分图和特征值分解工作区。

现有动量耗散量还包含

$$
\frac{(p^n)^\top\mathbf M^np^n}{2\eta}.
$$

运行中改变 η 会改变动能权重，现有固定步长证明不能直接沿用；动量方向也不保证满足当前
Armijo 所需的下降方向条件。因此本轮采用“先校准、后固定”，不新增变步长动量算法。

### 校准规则

所有候选使用同一训练 / 验证集、初始化种子 0 和 5,000 步，测试集不参与。

| 方法 | 首轮候选 η | 选择规则 |
| --- | --- | --- |
| PB-SAV | 0.001、0.003、0.01 | 完成预算的有限记录中，末步总目标 E 最小 |
| SGD 动量 | 0.003、0.01、0.03 | 同上 |
| Adam | 0.0003、0.001、0.003 | 同上 |
| AdamW | 0.0003、0.001、0.003 | 末步验证集平均相对 L2 最小 |

并列时选较小学习率。验证曲线同时检查泛化表现，但不替换同目标组的选择标准。
最优落在候选边界时，沿 `{1,3}×10^j` 序列向该方向扩一档；
每种方法最多 5 个候选，保留全部失败记录。
若有限候选均无有效进展，先检查实现、尺度和步长范围，不把这类基线当作正常对手。

PB-SESAV 直接使用 PB-SAV 选出的 η*，不为它额外调 k 或选择有利步长。
全部设置在打开正式测试结果前冻结。正式主表为 5 方法 × 5 配对初始化，共 25 组独立 run。

PB 两方法对齐 η、步数及优化伪时间 5000η；各自调参的常规基线只作同更新预算、同机器耗时比较，
不称为同时间步离散比较。若以后分析 Relax 或缩放的独立贡献，再单独设计一次只改一个因素的对照。

相对 L2 按每个场分别计算再平均：

$$
\frac1{N}\sum_{j=1}^N
\frac{\|s v_\theta(a_j;\cdot)-u_j\|_2}{\|u_j\|_2}.
$$

主结果表：方法及梯度目标、η、完成数 / 5、实际步数、末态 E / E₁ / E₂、测试相对 L2、耗时。
完整实验报五个初始化的均值 ± 样本标准差，并列出 PB-SESAV 减 PB-SAV 的逐种子差值。
失败组保留最后有效值单列；不将其伪装成固定预算的末态，也不只统计成功种子。

图表只读已保存记录：E / E₁ 对更新次数与累计更新耗时、验证相对 L2 曲线、五个配对测试点、
预先固定的测试样本 0 的系数场 / 参考解 / 预测误差。原始曲线不平滑，误差图共用色标。

先依据同级 PB-SAV 的最后有效 E 判断优化效果；预测精度单独依据测试相对 L2 判断。
若 E 更低而测试误差更高，就分别陈述这两个结果。
辅助耗散只验证结构，不能代替优化或泛化效果；不将单一均值较低写成显著优势。

### 实施后的验证顺序

1. **数据与参考解**：重新生成的张量哈希一致、三个集合无重复、零边界、正系数、线性残差合格；
   用常系数正弦制造解核对 17 / 33 / 65 网格上的约二阶收敛。
   主结论限定为 33×33 离散算子；连续 PDE 精度需另做同一系数场的网格加密检查。
2. **损失与输入**：尺度只由训练集确定，零预测 E₁=1/2；分量梯度之和等于总梯度；
   五种方法初值相同，AdamW 无重复正则，PB 初始分量能量为正。
3. **小规模接入**：8 个训练场、少量验证场、20 步，检查五种方法、诊断、记录、模型重载与绘图；
   检查受影响的旧问题入口。临时脚本先保存于 `TMP/`，用完删除。
4. **校准与冻结**：先确认基线正常下降，再按预定规则选步长、固定协议；之后才进入 25 组正式比较。
